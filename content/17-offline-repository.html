InMemory datasource

Deterministic implementation
final class InMemoryTaskDatasource {
  InMemoryTaskDatasource({
    List<TaskRecord> seed = const [],
  }) : _records = [...seed];

  final List<TaskRecord> _records;

  Future<List<TaskRecord>> readAll() async {
    return List.unmodifiable(_records);
  }

  Future<TaskRecord?> insert(TaskRecord record) async {
    final index = _records.indexWhere((item) => item.id == record.id);
    if (index != -1) return null;
    _records.add(record);
    return record;
  }

  Future<TaskRecord?> update(TaskRecord record) async {
    final index = _records.indexWhere((item) => item.id == record.id);
    if (index == -1) return null;
    _records[index] = record;
    return record;
  }
}

คืน unmodifiable snapshot ป้องกัน repository/caller mutate source โดยไม่ผ่าน datasource method และแยก insert/update semantics: duplicate insert กับ missing update จะคืน null ให้ repository แปลงเป็น typed failure แทนการ upsert จน CRUD bug ถูกซ่อน การ inject seed ทำให้ test สร้าง scenario ได้ชัด

Repository mapping

TaskRepositoryImpl
Result<Task> _toEntity(TaskRecord record) {
  final createdAt = DateTime.tryParse(record.createdAtIso);
  if (createdAt == null) {
    return const FailureResult(
      ValidationFailure(
        userMessage: 'Stored task data is invalid.',
      ),
    );
  }
  return Task.restore(
    id: record.id,
    title: record.title,
    description: record.description,
    isCompleted: record.completed,
    createdAt: createdAt,
  );
}

TaskRecord _toRecord(Task task) {
  return TaskRecord(
    id: task.id,
    title: task.title,
    description: task.description,
    completed: task.isCompleted,
    createdAtIso: task.createdAt.toIso8601String(),
  );
}

Task.restore คืน Result<Task> และใช้ invariant ชุดเดียวกับ create/update ดังนั้น blank title, ID ว่าง, text เกิน limit หรือ timestamp ที่ parse ไม่ได้จะไม่กลายเป็น invalid Domain object

Repository behavior tests

  • read คืน seed ตามลำดับและ caller แก้ list ไม่ได้
  • create trim/validate ผ่าน domain path และใช้ injected id/time
  • update รักษา id/createdAt
  • create ที่ generate ID ซ้ำคืน ValidationFailure และไม่เขียนทับของเดิม
  • update ID ที่ไม่มีคืน NotFoundFailure และไม่ insert แอบแฝง
  • persisted record ผิด invariant คืน typed failure
  • toggle task ที่ไม่มีคืน NotFoundFailure
  • delete แล้ว read ไม่พบ
  • datasource exception ถูก map เป็น UnknownFailure โดยไม่เปิด internal message ให้ UI

final taskLocalDatasourceProvider = Provider<TaskLocalDatasource>(
  (ref) => InMemoryTaskDatasource(seed: TaskSeed.defaults),
);

final taskRepositoryProvider = Provider<TaskRepository>(
  (ref) => TaskRepositoryImpl(
    datasource: ref.watch(taskLocalDatasourceProvider),
    idGenerator: () => 'task-${DateTime.now().microsecondsSinceEpoch}',
    clock: DateTime.now,
    errorMapper: const ErrorMapper(),
    logger: ref.watch(appLoggerProvider),
  ),
);

ข้อผิดพลาดที่พบบ่อย

  • เรียก DateTime.now/random ใน test path โดย inject ไม่ได้
  • คืน internal mutable list
  • ให้ datasource คืน Result ซึ่งเป็น application concern ทุก implementation
  • เขียน repository เป็น pass-through จนไม่มี mapping/policy
  • ทำ offline datasource เป็น global singleton นอก provider lifecycle
