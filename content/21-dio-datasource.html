สมมติ API contract

Response shape
{
  "data": [
    {
      "id": "task-1",
      "title": "Learn Dart",
      "description": "Practice records",
      "completed": false,
      "created_at": "2026-07-24T10:00:00Z"
    }
  ]
}

JSON เป็น untrusted input แม้ backend ทีมเดียวกัน ต้องทดสอบ missing key, wrong type, null และ invalid date ไม่ใช้ as กระจายโดยไม่มี mapping policy

DTO และ JSON mapping

task_dto.dart
@freezed
sealed class TaskDto with _$TaskDto {
  const factory TaskDto({
    required String id,
    required String title,
    @Default('') String description,
    required bool completed,
    @JsonKey(name: 'created_at') required DateTime createdAt,
  }) = _TaskDto;

  factory TaskDto.fromJson(Map<String, Object?> json) =>
      _$TaskDtoFromJson(json);
}

Remote datasource

TaskRemoteDatasource
final class TaskRemoteDatasource {
  const TaskRemoteDatasource(this._client);
  final ApiClient _client;

  Future<List<TaskDto>> readAll() {
    return _client.get(
      '/tasks',
      decode: (data) {
        final root = data as Map<String, Object?>;
        final items = root['data'] as List<Object?>;
        return items
            .map((item) => TaskDto.fromJson(
                  item as Map<String, Object?>,
                ))
            .toList(growable: false);
      },
    );
  }
}
Cast error ต้องถูกจำแนก code ตัวอย่างชี้ตำแหน่ง decode แต่ production implementation ต้องจับ CheckedFromJsonException, TypeError หรือ format error ที่ boundary แล้ว map เป็น schema-specific AppException พร้อม diagnostic

test('decodes a valid task list', () async {
  adapter.replyJson('/tasks', {
    'data': [
      {
        'id': 'task-1',
        'title': 'Learn Dart',
        'completed': false,
        'created_at': '2026-07-24T10:00:00Z',
      },
    ],
  });

  final tasks = await datasource.readAll();
  expect(tasks.single.id, 'task-1');
});

test('maps malformed payload to schema exception', () async {
  adapter.replyJson('/tasks', {'data': [{'id': 42}]});

  expect(
    datasource.readAll,
    throwsA(isA<SchemaAppException>()),
  );
});

เลือก implementation ตาม environment

Fail-closed composition
TaskRepository taskRepository(Ref ref) {
  final config = ref.watch(appConfigProvider);
  return switch (config.environment) {
    AppEnvironment.development => TaskRepositoryImpl(
        ref.watch(taskLocalDatasourceProvider),
      ),
    AppEnvironment.staging ||
    AppEnvironment.production => RemoteTaskRepository(
        ref.watch(taskRemoteDatasourceProvider),
      ),
  };
}

ถ้า remote implementation/config ไม่พร้อม Production ควร fail bootstrap ไม่ fallback ไป fake/local แล้วแสดง label Production

Transport security checklist

  • HTTPS และ certificate policy
  • timeout แยก connect/send/receive
  • auth header injection จาก session abstraction
  • redact token/password/body ใน logs
  • 401 refresh queue ป้องกันหลาย request refresh พร้อมกัน
  • schema/version compatibility และ observability

ข้อผิดพลาดที่พบบ่อย

  • ใช้ public API เป็น dependency ของ onboarding/test ทั้งหมด
  • map JSON ใน Widget
  • catch เฉพาะ DioException แล้วปล่อย schema error raw
  • ส่ง Entity.toJson เป็น request ทุก endpoint
  • fallback Production ไป fake datasource เมื่อ config ขาด
