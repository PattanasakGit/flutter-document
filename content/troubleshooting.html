ข้อมูลที่ควรแนบเมื่อขอความช่วยเหลือ

  • expected vs actual และขั้นตอน reproduce ขั้นต่ำ
  • exact command + first actionable error/stack trace
  • Flutter/Dart/platform/tool versions
  • sanitized relevant code/diff และ test ที่ fail
  • สิ่งที่ลองแล้วพร้อมผล ไม่ใช่เพียงรายการคำสั่ง
  • ห้ามแนบ token, key, personal payload หรือ unredacted logs

ข้อผิดพลาดที่พบบ่อย

  • แก้ error 20 บรรทัดท้ายแทน error แรกที่เป็นสาเหตุ
  • upgrade SDK/packages ทั้งหมดเพื่อแก้ปัญหาเฉพาะจุด
  • ลบ lockfile/build/cache/pods พร้อมกันโดยไม่เก็บหลักฐาน
  • ซ่อน error ด้วย cast, !, catch เปล่า หรือ ignore lint
  • หยุดเมื่อ focused test ผ่านโดยไม่รัน related/full verification
