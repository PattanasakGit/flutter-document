เป้าหมายของบท

  • แปลง requirement เป็น invariant และ domain type
  • เขียน failing tests ก่อน entity/use case
  • ออกแบบ repository contract โดยไม่รู้ datasource implementation
  • แยก UI validation feedback จาก domain rule

Requirement ของ Task

  • Task มี id, title, description, completion และ createdAt
  • title หลัง trim ต้องไม่ว่างและไม่เกิน 120 ตัวอักษร
  • description ไม่เกิน 500 ตัวอักษร
  • การแก้ไขต้องไม่เปลี่ยน id/createdAt
  • filter มี all, open และ completed
จาก TypeScript interface interface บอก shape ได้ แต่ invariant ต้องมี creation/update path ที่ไม่ปล่อย invalid object หลุดออกมา Dart class + use case ทำ contract นี้ ให้ analyzer และ test มองเห็น

GREEN: minimal entity

Task.create
static Result<Task> create({
  required String id,
  required String title,
  String description = '',
  required DateTime createdAt,
}) {
  final cleanTitle = title.trim();
  final cleanDescription = description.trim();

  if (cleanTitle.isEmpty) {
    return const Error(ValidationFailure(message: 'กรุณากรอกชื่องาน'));
  }
  if (cleanTitle.length > 120 || cleanDescription.length > 500) {
    return const Error(
      ValidationFailure(message: 'ข้อมูลยาวเกินขอบเขตที่กำหนด'),
    );
  }

  return Success(Task._(
    id: id,
    title: cleanTitle,
    description: cleanDescription,
    isCompleted: false,
    createdAt: createdAt,
  ));
}

Filter เป็น domain vocabulary

TaskFilter
enum TaskFilter {
  all,
  open,
  completed;

  bool matches(Task task) => switch (this) {
    TaskFilter.all => true,
    TaskFilter.open => !task.isCompleted,
    TaskFilter.completed => task.isCompleted,
  };
}

label ภาษาไทยไม่อยู่ใน Domain เพราะต้อง localize ใน Presentation แต่ matching rule เป็น domain behavior ที่ test โดยไม่เปิด Flutter ได้

Repository contract

domain/repositories/task_repository.dart
abstract interface class TaskRepository {
  Future<Result<List<Task>>> getTasks();
  Future<Result<Task>> create({
    required String title,
    required String description,
  });
  Future<Result<Task>> update(Task task);
  Future<Result<Task>> toggle(String id);
  Future<Result<void>> delete(String id);
}

Contract พูดภาษา Task ไม่พูด JSON, Dio, database row หรือ secure storage ทำให้ application tests ใช้ fake repository ได้

Use case รับผิดชอบ orchestration

CreateTask
final class CreateTask {
  const CreateTask(this._repository);
  final TaskRepository _repository;

  Future<Result<Task>> call({
    required String title,
    String description = '',
  }) {
    return _repository.create(
      title: title,
      description: description,
    );
  }
}
