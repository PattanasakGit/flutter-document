# AI-First Flutter Starter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-ready, runnable Flutter starter named `ai_first_flutter_starter` with one complete authentication reference slice, a lean home feature, deterministic tests, CI, and AI-first documentation.

**Architecture:** Organize code feature-first and add light clean layers only when a responsibility exists. Riverpod owns state and dependency injection, GoRouter owns navigation and redirects, Dio stays inside core/data boundaries, and repositories convert external exceptions and DTOs into typed domain results.

**Tech Stack:** Flutter 3.44.8, Dart 3.12.2, Riverpod, GoRouter, Dio, Freezed, json_serializable, flutter_secure_storage, mocktail, very_good_analysis.

## Global Constraints

- Create Android, iOS, and Web only; do not create desktop platforms.
- Use development, staging, and production entry points.
- Use Riverpod exclusively for state management and dependency injection.
- Use GoRouter exclusively for application routing.
- Use Dio exclusively for HTTP.
- Keep Dio exceptions, raw JSON, and DTOs out of presentation.
- Do not install optional product modules.
- Do not create empty architecture layers.
- Tests must be deterministic and must not call a live network or platform storage channel.
- Completion requires clean formatting, generated code, `flutter analyze`, and `flutter test`.

```dart
Failure mapException(Object error) => switch (error) {
  UnauthorizedAppException() => const UnauthorizedFailure(),
  ForbiddenAppException() => const ForbiddenFailure(),
  NotFoundAppException() => const NotFoundFailure(),
  ValidationAppException(:final message) =>
    ValidationFailure(userMessage: message),
  TimeoutAppException() => const TimeoutFailure(),
  NetworkAppException() => const NetworkFailure(),
  ServerAppException() => const ServerFailure(),
  _ => const UnknownFailure(),
};
```
